# Облачная AI-команда из девяти LLM-специалистов

## Архитектура
- GitHub Actions hosted runner выполняет всё в облаке; компьютер владельца не нужен и не используется.
- Девять отдельных вызовов Gemini API — по одному на каждую роль. Это девять реальных LLM-исполнений с отдельными системными задачами, а не девять названий в одном отчёте.
- Модель по умолчанию строго зафиксирована на gemini-2.5-flash-lite (free tier). Любой override модели блокируется.
- Исследователь конкурентов — единственный агент с Google Search grounding; он автоматически ищет сайты и компании в заданной нише.
- Результаты агентов последовательно передаются дальше как общий контекст.
- Отчёт сохраняется в GitHub Actions artifact.

## Девять ролей
1. Гений креатива
2. Исследователь конкурентов (Google Search grounding)
3. SEO-эксперт
4. Главный редактор
5. UX/UI-дизайнер
6. Маркетолог / аналитик
7. Разработчик
8. QA-контролёр
9. Стратег / Project Manager

## Бесплатный тариф и защита от расходов
По официальной таблице Google AI Studio для Gemini 2.5 Flash-Lite бесплатны входные и выходные токены; Google Search grounding — до 500 запросов в день, общий лимит с Gemini 2.5 Flash. Тарифы и квоты меняются: проверяйте перед эксплуатацией.
- Жёсткий лимит в коде: ровно не более 9 вызовов модели за запуск.
- Жёсткий лимит в коде: не более 1 вызова с поисковым grounding за запуск.
- Запуск по расписанию один раз в сутки плюс ручной запуск.
- Нет повторных попыток, переключения на платную модель или платного fallback.
- Если ключ, квота или бесплатный доступ недоступны — запуск останавливается.
- Для гарантированного нулевого счёта создайте Google AI Studio API key в проекте без подключённого биллингового аккаунта. Не включайте платный тариф и не привязывайте платёжный профиль. GitHub Actions хранит только секрет GEMINI_API_KEY.
- Кодовые лимиты защищают от лишних вызовов, но нулевой счёт обеспечивается также настройкой проекта провайдера. Не подключайте биллинг к проекту.

## Конфиденциальность
Google указывает, что данные Free tier могут использоваться для улучшения продуктов. Не передавать ключи, персональные, финансовые или иные конфиденциальные сведения. В контекст попадают публичные материалы сайта.

## Настройка
1. Откройте https://aistudio.google.com/app/apikey и создайте API key на бесплатном тарифе.
2. Убедитесь, что к проекту не подключён биллинг.
3. В GitHub откройте Settings → Secrets and variables → Actions → New repository secret.
4. Имя секрета: GEMINI_API_KEY. Значение: созданный ключ.
5. Вкладка Actions → Cloud AI team → Run workflow.
6. Результат ищите в Actions → выбранный запуск → Artifacts.

## Ограничения
- Google Search ищет публично индексируемые страницы, но не раскрывает продажи, трафик, конверсии, рекламу или закрытые кабинеты конкурентов.
- Поисковые результаты и LLM-выводы требуют проверки; отчёт сохраняет источники, если grounding их вернул.
- GitHub-hosted runner не является постоянно работающим сервером: он запускает ежедневную задачу и завершает работу. Это достаточно для отчётов, но не для круглосуточного процесса.
- Запуск не изменяет сайт, не создаёт PR, не делает merge и не публикует.
- Для автоматических изменений в будущем нужны отдельные права, проверка diff и одобрение владельца.
