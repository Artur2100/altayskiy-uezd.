# AI Team Runtime — бесплатная локальная команда

## Два режима
1. GitHub Actions: ежедневный детерминированный аудит без AI API и веб-запросов.
2. Windows: девять LLM-работников через локальный Ollama; запросы идут на localhost, платные API и облачные модели не используются.

## Windows: первый запуск
1. Установи Python 3.10+.
2. Установи Ollama для Windows: https://ollama.com/download
3. В PowerShell выполни: ollama pull qwen2.5:7b (модель можно заменить на более лёгкую при нехватке памяти).
4. Из корня репозитория выполни:
   python scripts/site_audit.py
   python -m unittest discover -s tests -v
5. Добавь публичные HTTPS URL конкурентов в config/competitors.json.
6. Выполни:
   python scripts/competitor_research.py
   python scripts/local_agent_team.py
7. Итог появится в reports/local-ai-team-YYYY-MM-DD-HHMM.md.

## Настройки модели
По умолчанию OLLAMA_HOST=http://127.0.0.1:11434 и OLLAMA_MODEL=qwen2.5:7b.

## GitHub Actions
Daily AI team report запускается вручную и ежедневно в 09:15 Asia/Barnaul. Hosted runner не имеет доступа к Ollama на компьютере владельца. Отчёты сохраняются как Actions artifacts; Telegram опционален.

## Конкурентный анализ
- Используются только HTTPS-страницы, URL которых владелец явно добавил в конфигурацию.
- Не используются поисковые API, платные SEO-платформы, аккаунты и закрытые кабинеты.
- Извлекаются заголовки, description, H1/H2, ориентировочный объём текста, изображения и внутренние ссылки.
- Не обходятся авторизация, paywall, CAPTCHA, robots/access controls или блокировки.
- Нет данных о реальном трафике, продажах, конверсиях и скрытых поисковых позициях.
- Автоматическое обнаружение новых конкурентов пока не реализовано: владелец добавляет адреса вручную.

## Безопасность
- Локальная модель обрабатывает контекст на этом компьютере.
- Не хранить пароли, токены и персональные данные в конфигурации.
- Агенты формируют отчёт и рекомендации, но не редактируют сайт и не выполняют git push, PR, merge или deploy.
- Факты о продукции и медицинские формулировки требуют ручной проверки.
