# Локальная AI-команда на Windows — бесплатно

## Что понадобится
- Python 3.10+
- Ollama для Windows: https://ollama.com/download
- Свободное место под локальную модель. Модель по умолчанию — qwen2.5:7b; на слабом компьютере выбери меньшую модель.

## Первый запуск
1. Установи Ollama с официального сайта и запусти приложение.
2. Открой PowerShell и выполни:
   `ollama pull qwen2.5:7b`
3. В папке репозитория установи Python-зависимости не нужно — инструменты используют стандартную библиотеку.
4. Запусти аудит сайта:
   `python scripts/site_audit.py`
5. Добавь публичные HTTPS-адреса конкурентов в `config/competitors.json`. Не добавляй личные кабинеты, закрытые страницы и ссылки, требующие авторизации.
6. Запусти сбор открытых данных:
   `python scripts/competitor_research.py`
7. Запусти девять локальных специалистов:
   `python scripts/local_agent_team.py`

## Переменные PowerShell (необязательно)
```powershell
$env:OLLAMA_MODEL = "qwen2.5:7b"
$env:OLLAMA_HOST = "http://127.0.0.1:11434"
python scripts/local_agent_team.py
```

## Что умеет система
- Девять специализированных LLM-проходов с общей памятью результатов внутри одного запуска.
- Анализ локальных исходников сайта.
- Сбор открытых SEO/контентных характеристик с URL, которые владелец сам добавил в конфигурацию.
- Сравнение публичных заголовков, описаний, структуры и объёма контента.
- Создание отчёта с рекомендациями и QA-критикой.

## Честные ограничения
- Модель работает на твоём компьютере; скорость и качество зависят от CPU/RAM/GPU.
- Никаких платных AI API, облачных LLM, подписок или платных SEO-сервисов.
- Анализ конкурентов требует загрузить их общедоступные страницы. Никакие сторонние SEO-платформы и поисковые API не используются. Автоматический поиск конкурентов пока не выполняется: URL добавляются вручную.
- Закрытые данные, продажи, рекламные кабинеты, реальные позиции и конверсии конкурентов недоступны.
- Агент формирует предложения, но не редактирует сайт, не делает git push, PR, merge и deploy.
- Медицинские утверждения и факты о товарах требуют проверки по первичным документам и надёжным источникам.

## Примечание по конфиденциальности
Локальная модель Ollama обрабатывает запросы на этом компьютере. Не публикуй конфиденциальные данные в открытых GitHub-репозиториях.
